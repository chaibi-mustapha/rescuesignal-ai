## 📌 Executive Summary

Whether trapped beneath earthquake rubble or facing a kidnapping, stalker pursuit, or hostage situation where speaking aloud would be fatal, victims often possess a smartphone but find themselves cut off from cellular reception and the Internet.

**RescueSignal AI** bridges this life-critical gap using an intelligent **Dual-Mode Emergency Pipeline**:

### 🎯 Two Life-Critical Emergency Modes:
1. **🎙️ Voice Distress Mode (Natural & Industrial Disasters)**:
   - For victims pinned under debris, choking on smoke, or trapped in floodwaters with zero touchscreen visibility.
   - The victim speaks naturally or whispers into their device (*"We are three people trapped under rubble. One person is injured in the leg and another is unconscious. Urgent medical assistance needed."*).
2. **🤫 1-Tap Silent Stealth Mode (Kidnappings, Pursuits & Hostile Threats)**:
   - For victims being followed, stalked, abducted, or hiding from intruders where **making any noise means detection and danger**, and there is zero time to waste.
   - A single silent tap captures disaster/threat type (`🚨 Kidnap/Threat`, `🏢 Rubble`, `🔥 Fire`), victims count, and urgency—generating and broadcasting a covert emergency beacon silently.

### ⚡ End-to-End Autonomous Pipeline:
1. **Voice Listening & Whispered Speech Processing**: Captures spoken or whispered distress calls with automatic noise reduction.
2. **AI Emergency Agent (AssemblyAI Speech-to-Text & LeMUR)**: Real-time semantic entity extraction identifying disaster/threat type (`BUILDING_COLLAPSE`, `KIDNAPPING_THREAT`, `FIRE`, `FLOOD`), victim count, injuries, unconscious individuals, and imminent hazards.
3. **Semantic Compression & Emergency Packet (RS1)**: Instant generation of an ultracompact *Emergency Data Packet* (35 to 45 bytes) secured with a **CRC16** integrity checksum (e.g., `RS1|SEC|P1|I0|U0|M1|HNIL|LOC#E4A7`).
4. **Resilient Multi-Modal Offline Transmission**:
   - 🔊 **Acoustic FSK & Morse Audio**: Frequency-shift keying audio bursts (1200 Hz / 2200 Hz) generated by the pure Web Audio API, penetrating rubble or air to reach nearby phones or search-and-rescue acoustic sensors.
   - 💡 **Optical Beacon (Strobe / Morse)**: Screen and flashlight pulsed sequences detectable by drones and aerial reconnaissance.
   - 📶 **Simulated Local P2P Mesh**: Covert Bluetooth Low Energy (BLE) and Wi-Fi Direct mesh transmission to nearby devices without cellular reception.
5. **Rescue Station Triage & Decoder**: Instant reception, acoustic FFT spectrum analyzer, CRC16 checksum verification, medical triage classification (**P1 Critical Red**, **P2 Urgent Orange**, **P3 Moderate Yellow**), and customized emergency response protocols (e.g. Police Dispatch for kidnappings/pursuits, Extrication Unit for collapses).

## 🌐 3-Tier Offline Resilience Architecture: How It Operates Without Internet

A critical question in disaster response: **How does an AI voice agent function when cellular towers and Internet backbones collapse completely?**

RescueSignal AI solves this through a **3-Tier Graceful Degradation Architecture**:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        3-TIER RESILIENCE PIPELINE                      │
├────────────────────────────────────────────────────────────────────────┤
│ TIER 1: CLOUD ASSEMBLYAI (Universal-1 Speech-to-Text & LeMUR)          │
│ • Deployed whenever disaster micro-relays (Starlink/drone mesh) exist. │
│ • Deep multi-language transcription & medical vocabulary boost.        │
├────────────────────────────────────────────────────────────────────────┤
│ TIER 2: EMBEDDED LOCAL SPEECH ENGINE (100% Offline Failover)           │
│ • Automatically triggers if AssemblyAI cloud connection drops to 0%.  │
│ • In-browser/on-device speech parser with sub-second zero-lag failover.│
│ • No internet connection required to extract critical triage data.     │
├────────────────────────────────────────────────────────────────────────┤
│ TIER 3: STEALTH SILENT TACTILE MODE (Zero Voice, Zero Connectivity)    │
│ • 1-click tactile grid for injured or silent victims in smoke/hazards. │
│ • Generates RS1 44-byte packet directly in device CPU.                 │
│ • Emits physical acoustic FSK sound & optical Morse strobes locally.   │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Tier 1 — AssemblyAI Cloud (High-Fidelity Gateway)**:  
   During search and rescue operations, rescue vehicles (emergency mobile trucks) or low-altitude surveillance drones often carry emergency Wi-Fi or satellite micro-gateways. As soon as a low-bandwidth channel opens, AssemblyAI's cloud models process raw audio with maximum phonetic accuracy and vocabulary boosting.

2. **Tier 2 — Embedded Local Fallback Engine (Zero Network)**:  
   If the terminal is completely isolated with **0% Internet availability**, our built-in fallback engine in [`assemblyai_service.py`](app/services/assemblyai_service.py) takes over seamlessly. The local client executes client-side entity extraction, identifying victim counts, unconscious states, and critical injuries without calling external cloud servers.

3. **Tier 3 — Silent Non-Verbal Touch Beaconing (Zero Sound, Zero Network)**:  
   When a victim cannot breathe or speak due to smoke inhalation, dust, or physical trauma, they activate **Silent Mode**. A single tap on the disaster preset generates the 44-byte RS1 packet entirely on-device and broadcasts it through the phone's physical speaker (FSK acoustic burst) and optical LED screen strobe without a single bit of Internet data.

## 🛡️ Emergency Data Packet Specification (RS1)

```text
Format : RS1|<SITUATION>|P<PEOPLE>|I<INJURED>|U<UNCONSCIOUS>|M<URGENCY>|H<HAZARD>|<LOCATION>|#<CRC16>
Example: RS1|BLD|P3|I1|U1|M1|HGAS|LOC_B2|#E4A7
```

- **Compression Ratio**: Over **70% smaller** than raw voice transcript text (~42 bytes vs. ~150+ bytes).
- **CRC16 Checksum**: 4-character hex checksum preventing corruption or false alerts in noisy acoustic and packet-loss environments.

## 🚀 Quickstart & Local Installation

### 1. Prerequisites
- Python 3.10+ (tested on Python 3.11, 3.12, and 3.13)

### 2. Setup
```bash
# Clone the repository
git clone https://github.com/chaibi-mustapha/rescuesignal-ai.git
cd rescuesignal-ai

# Install dependencies
pip install -r requirements.txt
```

### 3. AssemblyAI API Key Configuration
Create a `.env` file or export your key:
```env
ASSEMBLYAI_API_KEY=your_assemblyai_api_key_here
```
*(If no key is configured, the built-in resilient offline fallback engine activates automatically)*.

### 4. Run the Server
```bash
python run.py
```

### 5. Access the Interfaces
- **Interactive Dual-Device Demo** (Recommended for evaluation & video recording):  
  👉 [http://localhost:8000/](http://localhost:8000/)
- **Standalone Victim Transmitter (Terminal A)**:  
  👉 [http://localhost:8000/victim](http://localhost:8000/victim)
- **Standalone Rescue Station & Triage (Terminal B)**:  
  👉 [http://localhost:8000/rescuer](http://localhost:8000/rescuer)
